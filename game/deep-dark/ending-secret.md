The frame doesn't fill with purple. It fills with a **terminal** — green text on
black, scrolling, familiar:

```console
[00:03:41 INFO]: Starting minecraft server version 26.2
[00:03:41 INFO]: Loading properties
[00:03:42 INFO]: Preparing level "deep_dark"
[00:03:44 INFO]: [SourbyCraft] Folia region scheduler online
[00:03:44 INFO]: Done (2.891s)! For help, type "help"
[00:03:44 INFO]: YanIanZ joined the game
```

The book was never a story. It was a **changelog**.

You were never lost in a cave. You were inside somebody's plugin, and he's been
debugging you since the first paragraph.

Somewhere above the bedrock, at 3 in the morning, a keyboard clicks twice and the
world reloads.
